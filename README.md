### 💫 About Me

I'm **Sakin Arshad Ayan**, a passionate **Frontend Developer** and **UI/UX Enthusiast** based in Bangladesh 🇧🇩. I specialize in building reactive, fluid, and user-centric web applications using **React** and modern frontend technologies.

- 🏛️ **Leadership:** Serving as the **Secretary of CPI ICT Club**, driving teamwork and tech initiatives.
- 💻 **Core Passion:** Crafting clean interfaces with smooth micro-interactions and scalable architecture.
- 🤖 **Currently Exploring:** **Python**, **Machine Learning fundamentals** (NumPy & Pandas), and **Prompt Engineering**.
- 💼 **Open To:** Freelance projects, junior frontend roles, and internship opportunities.
